📅 Day 4 — Computer Systems & Cloud Fundamentals
🧠 Overview

Today I explored the fundamental concepts behind modern IT infrastructures, including computer systems, client-server architecture, virtualization, cloud computing, and operating systems.

These topics provide the foundation for Cloud Engineering, DevOps, and Cybersecurity careers.

💻 Rooms Completed
🖥️ Computer Types

What I learned

Different categories of computers and their purposes
Servers, desktops, laptops, mobile devices, and embedded systems
How hardware requirements vary depending on workloads

🌍 Real-World Application

Companies use dedicated servers to host websites, applications, and databases.
Cloud providers operate thousands of physical servers inside large-scale data centers.
🌐 Client-Server Basics

What I learned

Difference between clients and servers
Request and response communication model
Basic network interactions between systems

🌍 Real-World Application

Every website follows a client-server model.
A browser sends requests to a server, which processes them and returns the requested content.
Modern applications such as Netflix, Spotify, and Amazon rely on this architecture.

Example Flow

User → Browser → Web Server → Database → Response
🖥️ Virtualisation Basics

What I learned

What virtualization is
Purpose of hypervisors
Physical vs virtual machines
Resource allocation and isolation

🌍 Real-World Application

Cloud providers use virtualization to host multiple virtual machines on the same physical hardware.
AWS EC2 instances are built on virtualized infrastructure.
Companies create development and testing environments without purchasing additional servers.
☁️ Cloud Computing Fundamentals

What I learned

Cloud service models (IaaS, PaaS, SaaS)
Scalability and elasticity
On-demand resource provisioning
Shared responsibility model

🌍 Real-World Application

Businesses can deploy applications globally without owning physical infrastructure.
Cloud resources can scale automatically during periods of high demand.
Organizations only pay for the resources they consume.

Examples

Service Model	Example
IaaS	AWS EC2
PaaS	Heroku
SaaS	Google Workspace
⚙️ Operating Systems: Introduction

What I learned

Purpose of operating systems
Process and memory management
User and hardware interaction
Core system functions

🌍 Real-World Application

Linux powers the majority of cloud servers worldwide.
System administrators manage users, permissions, services, and processes through the operating system.
Understanding operating systems is essential for Cloud, DevOps, and Security roles.
