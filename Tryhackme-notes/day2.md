## 🧱 OSI Model

### 🧠 What I learned
- The 7 layers of the OSI model
- How data travels through a network
- Encapsulation / decapsulation process

### 📊 OSI Layers
1. Physical  
2. Data Link  
3. Network  
4. Transport  
5. Session  
6. Presentation  
7. Application  

### 🔑 Key takeaways
- Layer 3 → IP (routing)
- Layer 4 → TCP / UDP (transport)
- Layer 7 → HTTP / DNS (applications)

### 🌍 Real-world connection
- Layer 3 → AWS VPC routing
- Layer 4 → HTTPS connections, load balancers
- Layer 2 → MAC addressing in networks
- Layer 7 → APIs, web apps, cloud services
