# 📦 Packets & Frames

### What I Learned
- Data travels across networks in the form of packets.
- Frames are used for communication on local networks.
- MAC addresses identify devices locally.
- IP addresses allow communication between networks.

### 🌍 Real-World Use Cases
- Troubleshooting connectivity issues.
- Understanding network traffic analysis.
- Investigating packet captures with Wireshark.

---

# 🌐 Extending Your Network

### What I Learned
- Switches connect devices within the same network.
- Routers connect multiple networks together.
- Subnets help organize network infrastructure.
- NAT allows multiple devices to share a public IP address.

### 🌍 Real-World Use Cases
- Home and enterprise networking.
- AWS VPC design and routing.
- Hybrid cloud infrastructure.

# 🔎 DNS in Detail

### What I Learned
- DNS converts domain names into IP addresses.
- Important DNS records:
  - A
  - AAAA
  - CNAME
  - MX
  - TXT
- DNS queries follow a hierarchical lookup process.

### 🌍 Real-World Use Cases
- Managing domains and websites.
- Configuring cloud services.
- Email delivery troubleshooting.

# 🌍 HTTP in Detail

### What I Learned
- HTTP enables communication between clients and servers.
- Common request methods:
  - GET
  - POST
  - PUT
  - DELETE
- Understanding response codes:
  - 200 OK
  - 301 Redirect
  - 404 Not Found
  - 500 Internal Server Error

### 🌍 Real-World Use Cases
- API testing.
- Web application troubleshooting.
- Understanding web traffic.

# 🖥️ How Websites Work

### What I Learned
- Websites consist of frontend and backend components.
- Browsers communicate with servers using HTTP/HTTPS.
- Databases store and retrieve application data.
- User requests trigger server-side processing.

### 🌍 Real-World Use Cases
- Web development.
- Cloud-hosted applications.
- Security testing and vulnerability assessment.
