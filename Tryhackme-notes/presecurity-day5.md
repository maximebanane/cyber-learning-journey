📅 Day 5 — Windows, Linux & OS Fundamentals 🧠
🧭 Overview

Today I focused on strengthening my core IT fundamentals across Windows, Linux, and Operating Systems security concepts, alongside data representation and encoding basics.
This is part of my path toward Cloud / DevSecOps (AWS-focused roadmap).

🪟 Windows Basics

📌 What I learned:
Understanding Windows architecture (GUI, kernel, system services)
File system structure (C:, Users, Program Files, System32)
Basic system navigation
Task Manager usage (processes, performance monitoring)
User accounts & permissions (Administrator vs Standard user)
🧠 Key takeaway:

Windows is heavily GUI-driven but still deeply dependent on system-level processes running in the background.

🐧 Linux CLI Basics

📌 Commands practiced:
ls        # list files
cd        # change directory
pwd       # current path
mkdir     # create folder
rm        # delete files
cp        # copy files
mv        # move/rename files
cat       # read file content
🧠 Key takeaway:

Linux is built around the CLI — mastering navigation and file manipulation is essential for cloud & security work.

🪟 Windows CLI Basics

📌 Commands practiced:
dir       # list files
cd        # change directory
cls       # clear screen
ipconfig  # network configuration
tasklist  # running processes
ping      # network test
🧠 Key takeaway:

Windows CLI (CMD / PowerShell) is powerful for system admin tasks and automation.

🔐 Operating System Security
📌 Concepts learned:
User privilege levels (admin vs standard)
File permissions and access control
Processes isolation
System updates and patch management
Malware entry points (downloads, services, USB, scripts)
🧠 Key takeaway:

Security starts at the OS level — most attacks exploit permissions and misconfigurations.

🔢 Data Representation

📌 Concepts:
Binary (0 and 1)
Bits vs Bytes
Base systems:
Decimal (base 10)
Binary (base 2)
Hexadecimal (base 16)
🧠 Key takeaway:

Everything in computing ultimately becomes binary — even images, text, and programs.

🔤 Data Encoding

📌 Concepts:
ASCII (basic character encoding)
Unicode (modern global standard)
UTF-8 (most used encoding on the internet)
🧠 Key takeaway:

Encoding defines how text becomes data — without it, computers cannot interpret characters correctly.

🚀 Summary

Today strengthened my understanding of:

Operating system fundamentals (Windows + Linux)
Command-line usage (CLI fluency building)
Security basics at OS level
How data is represented and encoded at the lowest level
