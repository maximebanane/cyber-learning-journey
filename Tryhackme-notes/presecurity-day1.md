## Key concepts learned

### Networking
- A network allows computers to communicate together
- Each device has an IP address
- LAN is a local network (home, office)
- Router connects local networks to the internet
- DNS translates domain names into IP addresses

### Offensive Security
- Offensive security = finding vulnerabilities in systems (legally)
- Goal is to identify weaknesses before attackers do

### Defensive Security
- Defensive security = protecting systems
- Monitoring, detecting and responding to attacks

### Cybersecurity roles
- Red Team = attack / penetration testing
- Blue Team = defense / monitoring / SOC
- Cloud / DevOps = infrastructure and cloud systems (AWS target path)
